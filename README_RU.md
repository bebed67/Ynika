# Школьный дневник Android — исходный проект

Это исходный Android-проект, который можно собрать в APK в Android Studio или в облачной сборке GitHub Actions.

## Важно
В этой среде не установлен Android SDK/Gradle, поэтому готовый APK нельзя честно приложить прямо отсюда. Этот ZIP — проект для сборки, не APK-файл.

## Как собрать APK
1. Загрузить проект в свой GitHub-репозиторий.
2. Открыть проект в Android Studio на компьютере или использовать облачную сборку Android.
3. Собрать через Gradle задачу `assembleDebug`.
4. APK появится по пути `app/build/outputs/apk/debug/app-debug.apk`.

## Текущий функционал
- Android-оболочка с названием и иконкой приложения по умолчанию.
- Демонстрационный список домашних заданий с локальным сохранением.
- Добавление и удаление задания.
- Адаптация интерфейса под телефон.

## Что ещё нужно до полноценного дневника
Общая база данных и регистрация учителей/учеников ещё не подключены. Для реального использования на разных телефонах нужно подключить серверную базу, аккаунты, права доступа и проверку безопасности.

## Сборка через GitHub с телефона
В проект включён workflow `.github/workflows/build-apk.yml`. После загрузки распакованных файлов проекта в репозиторий GitHub:
1. Открой вкладку Actions.
2. Выбери `Build Android APK`.
3. Нажми `Run workflow` (или сделай push в ветку main).
4. Когда сборка завершится, открой запуск workflow и скачай artifact `shkolny-dnevnik-debug-apk`.
5. Распакуй artifact ZIP и установи `app-debug.apk` на Android. Android может попросить разрешить установку из этого источника.

Это debug APK для личного тестирования, не подписанный релиз для публикации в Google Play.
